# TOST'D — The One Stop Drop (Site Mock)

Frontend-only mockup of The One Stop Drop's public site. React + Vite + Tailwind + MUI.

- **Live:** https://tostd.francces.co
- **Pitch deck (separate site):** https://deck.francces.co
- **Deploy:** pushes to `main` auto-deploy to GitHub Pages via Actions.

## Development

```
npm install
npm run dev
```

## Content

- Page copy: `src/content/site.js`
- Artist roster / marketplace data: `src/data/artists.js`
- Images are placeholders — swap as real assets arrive.
